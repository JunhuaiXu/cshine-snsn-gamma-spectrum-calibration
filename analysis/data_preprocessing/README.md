# DataPreprocessing: current active stage

This is the only active core-analysis stage while the experimental-analysis
part of the thesis is being reviewed. It covers the path from calibration and
timing information to the measured detector-level gamma-ray spectrum.

## Historical server structure

| Historical path | Physical role | Current use |
|---|---|---|
| `DataPreprocessing/step0-nobkg/` | radioactive-source background subtraction | provenance and input tracing |
| `DataPreprocessing/step1-2D/` | low-/high-gain channel relation | provenance and input tracing |
| `DataPreprocessing/step2-fit/` | crystal energy-calibration objects | provenance and input tracing |
| `DataPreprocessing/step3-time/` | time-amplitude fit and time correction | active figure tracing |
| `DataPreprocessing/step4-convert*` | run-by-run reconstruction and measured spectra | central chain traced; `step4-convert.0308.PreRun` event trees are the current Sec. 3.3.2 figure input; historical production code is not rerun |
| `DataPreprocessing/step7-DeltaYrelated/` through `step11-otherFigsLongPaper/` | reconstruction, timing, trigger, and figure checks | inspect only when a thesis figure requires it |

Detailed call graphs, server paths, and the central-spectrum file chain remain
in private thesis-workspace provenance records outside this public-safe
project. This README contains only the portable analysis contract needed by a
repository user.

## Current migration boundary

The Python plotting programs reproduce selected thesis figure layouts, but
they do not constitute a migration of the upstream analysis. The migrated
scope covers the complete Chapter 3 central `DataPreprocessing` chain:

1. source-background subtraction;
2. low-/high-gain relation;
3. crystal energy calibration;
4. time-amplitude correction;
5. event-level `GammaEnergy[15]` and `GammaTime[15]` production;
6. shower reconstruction and reviewed veto conditions;
7. run-by-run processing, merging, and diagnostic ROOT objects;
8. slow- and fast-coincidence background treatment;
9. the final detector-level measured spectrum and its downstream input contract.

The historical ROOT plotting implementations remain authoritative and will be
retained alongside portable ROOT entries. Python plotting is an optional
presentation layer and must be validated against the corresponding ROOT
histograms. M1--M4 are migrated. M5 is code-migrated to the limit supported by
the surviving evidence: the original time-amplitude histogram producer, the
historical diagnostic producer, the published 15-channel parameter
application, and the distinct diagnostic expression are implemented and
synthetic-data tested. A bounded server inventory also confirms
that the historical batch-fit producer is absent from both the archived source
and the surviving `step3-time` directory. The 15 ROOT/text output pairs are
therefore treated as immutable historical inputs and checked by
`inspect_time_fit_outputs`; they are not regenerated by a replacement fit.
M6 is now code-migrated within the event-level calibration boundary described
below. M7 provides the six authoritative neighboring-crystal timing
diagnostic objects used in Sec. 3.3.2. M8 now migrates the per-event shower
reconstruction, crystal roles, three-face veto definition, and historical
per-run spectra. M9 migrates the reviewed 60-group beam-on and six-group
beam-off orchestration and spectrum merge. M10A now migrates the reviewed
central beam-on/beam-off diagnostic objects; M10B migrates the trigger monitor and
five trigger-conditioned branches. M11 migrates the slow beam-off and fast
equal-width random-window background routes. M12 freezes the observed-spectrum
input contract without migrating later physics analyses. M13 has closed the
reproduction records, navigation, and public-boundary audit. M0B has frozen
the reviewed central M9--M12 producers, the M10B trigger branches, the M11 fast
branch, and the complete historical before/after reconstruction spectrum
chain. Its exact 59-group figure sample is recorded separately from the

code-migration complete; the published 15-channel calibration coefficients
have intentionally not been regenerated from experimental inputs.

Installation includes the calibration shared library, source/background and
gain-relation and energy-calibration static libraries and executables, public
headers, ROOT PCM, and rootmap:

```bash
cd build
cmake -DCMAKE_INSTALL_PREFIX=/desired/install/prefix ..
cmake --build . --target install
```

The detailed internal migration plan and exact collaborator paths are
maintained outside this public repository. The compact public stage-level
input/output crosswalk is provided in
[`../../docs/ANALYSIS_IO_MAP.md`](../../docs/ANALYSIS_IO_MAP.md).
